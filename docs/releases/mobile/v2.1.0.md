## Executive Summary

iKeen 2.1.0 introduces a comprehensive **Note Reminders subsystem**, **Server Push Notifications pipeline**, **AI SDK v7 streaming lifecycle fidelity**, and **User Privacy & Account Deletion compliance**, coupled with **-1,249 net lines of code consolidation** across the monorepo.

With native scheduled notifications via `expo-notifications`, a dedicated `ReminderSheet` with quick presets, interactive note card reminder chips featuring 1-tap circular completion buttons, multi-device server push alerts triggered on AI Agent creations, and robust tool card stream state handling, v2.1.0 elevates iKeen into a proactive thought partner.

## What's New & Fixed in v2.1.0

### 1. Note Reminders Subsystem & Local Notification Engine
* **Discrete Schema & Storage** ([`apps/mobile/src/db/schema.ts`](../../../apps/mobile/src/db/schema.ts)):
  * Added dedicated `reminders` table with foreign key to `notes.id`, `dueAt`, `repeat` interval (`none`, `daily`, `weekly`, `monthly`), `completedAt`, and `deletedAt`.
  * Fully synchronized through the local-first `sync_outbox` engine with Last-Write-Wins (LWW) conflict resolution.
* **Reminder Scheduling Engine** ([`apps/mobile/src/lib/services/reminder-service.ts`](../../../apps/mobile/src/lib/services/reminder-service.ts)):
  * Direct OS-level notification scheduling via `expo-notifications` with custom audio channels and exact alarm triggers.
  * Native deep-linking handler routing directly to [`/notes/[id]`](../../../apps/mobile/src/app/notes/[id]/index.tsx) upon tapping a delivered reminder notification.
* **Interactive UI Surfaces**:
  * [`reminder-sheet.tsx`](../../../apps/mobile/src/components/notes/reminder-sheet.tsx): Quick presets (Later Today 6 PM, Tomorrow 9 AM, Next Week), custom datetime pickers, and recurring interval selectors.
  * [`note-card.tsx`](../../../apps/mobile/src/components/notes/note-card.tsx): Non-deleted reminders loop with uncompleted-first sorting. Right-aligned circular inline check buttons (`hitSlop={8}`) to toggle completion state with haptic feedback without opening the card.
  * [`reminders.tsx`](../../../apps/mobile/src/app/reminders.tsx): Dedicated screen for viewing, filtering, and managing all upcoming and completed workspace reminders.

### 2. Multi-Token Server Push Notifications Engine
* **Expo Push Dispatcher** ([`apps/api/src/modules/notifications/push-notification.service.ts`](../../../apps/api/src/modules/notifications/push-notification.service.ts)):
  * Powered by `expo-server-sdk` (v8.0.0). Handles multi-token per device and multi-device per user tracking.
  * Automatic dead token pruning on `DeviceNotRegistered` ticket responses.
* **Creation-Only AI Agent & MCP Triggers**:
  * Seamless notification dispatch when the AI Agent or connected tools create new notes, folders, or reminders on behalf of the user.
* **Mobile Client Auto-Registration** ([`apps/mobile/src/lib/services/push-token.service.ts`](../../../apps/mobile/src/lib/services/push-token.service.ts)):
  * Hardware metadata caching and permission checks on login; automatic token deregistration on logout.

### 3. AI SDK v7 Streaming Lifecycle & Unified Tool Cards
* **Streaming Lifecycle States** ([`apps/mobile/src/components/chat/chat-tool-part.tsx`](../../../apps/mobile/src/components/chat/chat-tool-part.tsx)):
  * Migrated tool cards to support full AI SDK v7 states (`input-streaming`, `input-available`, `output-available`, `output-error`).
  * Real-time progress spinners (`Loader2`) spin continuously during active tool execution, and action buttons ("Open Note", external links) are protected from premature interaction.
* **Reusable UI Presenter Primitives**:
  * Consolidated 10+ divergent tool views into `ToolActionCard` and `ToolCompactRow`, reducing tool card complexity from 939 to 544 LoC.
* **Streamlined Chat Input Bar** ([`apps/mobile/src/components/chat/chat-input-bar.tsx`](../../../apps/mobile/src/components/chat/chat-input-bar.tsx)):
  * Removed 205 lines of legacy dead code, implementing an accessible stop-generation toggle.

### 4. Schema Resilience & $O(1)$ Wire Budgets
* **Tool Schema Nullable Normalization** ([`apps/api/src/modules/agent/call-options.ts`](../../../apps/api/src/modules/agent/call-options.ts)):
  * Standardized all tool schemas with `optionalNullable` and `defaultNullable` to safely handle LLM-provided `null` arguments, completely eliminating `rawInput` deprecation warnings and `InvalidToolInputError`.
* **Wire Payload Size Budget** ([`apps/mobile/src/app/agent/index.tsx`](../../../apps/mobile/src/app/agent/index.tsx)):
  * Mobile client transmits **only the latest user message** on turn submission, relying on server conversation persistence and context pruning (`pruneMessages`) to avoid HTTP 413 "Request Entity Too Large".

### 5. User Privacy & Account Deletion Compliance
* **In-App Account Deletion Action** ([`apps/mobile/src/app/(tabs)/profile/index.tsx`](../../../apps/mobile/src/app/(tabs)/profile/index.tsx)):
  * Integrated interactive account deletion trigger in the Profile settings opening `ACCOUNT_DELETION_URL` via `openBrowserAsync`, meeting Apple App Store & Google Play privacy compliance requirements.

  * Added `reminders` table with columns: `id`, `note_id`, `user_id`, `due_at`, `repeat`, `completed_at`, `created_at`, `updated_at`, `deleted_at`.

* **Backend PostgreSQL Schema (`apps/api/prisma/schema.prisma`)**:
  * Added `model Reminder` and `model PushToken`.
  * Added `SyncEntity.reminders` enum.
