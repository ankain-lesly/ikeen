# iKeen Mobile v2.3.0 Release Notes

**Release Version:** `2.3.0`  
**Internal Build:** `10`  
**Release Date:** `2026-11-26`  
**Target Platforms:** Android (`com.techforgelee.ikeen`), iOS  
**Codename:** *External Share Target, Outbox Ledger Parity & Note Editor Agility*  

---

## Executive Summary

iKeen 2.3.0 delivers three major capabilities across mobile architecture:

1. **Native Share Target Ingestion (`expo-share-intent`)**: Full support for receiving shared text, links, photos, and files directly from third-party Android and iOS apps into iKeen. Features automated title inference, live asset sandboxing, instant note search, and granular block vs. body insertion controls via `@expo/ui` switches.
2. **Sync Outbox Desktop Parity & Network Resilience**: Complete overhaul of the mobile Sync Outbox screen to achieve 1:1 parity with the desktop ledger. Introduces interactive status metric cards, real-time client-side search, manual retry/clear operations, formatted JSON payload inspection, and intelligent transient error classification that prevents network blips from ever penalizing outbox tasks as "failed".
3. **Decoupled Note Editor Actions**: Major UX agility refinement decoupling non-text creator operations from `isEditing` mode. Users can now attach photos, take pictures, record voice memos, attach documents, add checklist items, and manage tags directly from the floating bottom toolbar in View Mode without opening the software keyboard, while strictly preserving native text selection and reading.

## Architectural & Subsystem Highlights

### 1. External Share Target Ingestion (`expo-share-intent`)
- **Native Intent Filters**: Configured `SEND` and `SEND_MULTIPLE` intent filters on Android and iOS Share Extension target.
- **Headless Ingestion Receiver**: `ShareIntentReceiver` mounted globally in `_layout.tsx`, deriving visibility at render time (`currentIntentKey !== dismissedIntentKey`) to eliminate cascading render warnings.
- **Permanent Media Sandboxing**: Shared temporary files are immediately copied to permanent sandboxed storage (`FileSystem.documentDirectory + "media/{images|files}/"`) via `saveAssetToSandbox()`.
- **Target Ingestion Sheet (`ShareTargetSheet`)**:
  - Live preview card displaying URL snippets, image thumbnails, or document metadata.
  - "Create New Note" tab with editable title and auto-generated media blocks.
  - "Add to Existing Note" tab featuring instant fuzzy search over local SQLite notes.
  - Native `@expo/ui` `AppSwitch` controls letting users choose between inserting separate discrete blocks or appending to note body/media blocks.

### 2. Mobile Sync Outbox Enhancement (Full Desktop Parity)
- **Clickable Status Filters**: Interactive cards for Pending, In Flight, Failed, and Success with live counts and active filter chips.
- **Instant Search**: Filter outbox queue in real time by entity (`notes`, `note_blocks`, `reminders`), mutation action (`upsert`, `delete`), entityId, or mutationId.
- **Action Toolbar**: "Sync Now" trigger, "Retry Failed" action (`retryFailedOutbox()`), and "Clear Clean" action (`clearSuccessfulOutbox()`).
- **Mutation Payload Inspector Modal**: View target entity, action, retry counter, error logs, and formatted JSON payload with one-tap clipboard copy.
- **Network Resilience Engine**: Refactored `classifySyncPushFailure` in `@repo/utils` to detect network drops, timeouts, socket errors, and HTTP status anomalies, classifying them as `transient_no_penalty` so tasks stay `pending` without penalty.

### 3. Note Editor Action Decoupling
- **Always-Accessible `+` Creation Action**: The floating minimal bottom toolbar in View Mode includes a `+` creation trigger.
- **Zero-Keyboard Media Capture**: Taking photos, selecting images, attaching files, and recording voice memos execute and persist directly to SQLite/media outbox without entering edit mode or popping the keyboard.
- **View-Mode Tag Management**: `+ Tag` chip is available directly in View Mode, prompting for a tag name and saving immediately.
- **Interactive Checklist Appending**: `+ Add item` at the bottom of checklists is accessible in View Mode, automatically focusing the input cursor for rapid entry.
- **Block Reordering & Options**: Contextual block OptionSheet includes Move Up, Move Down, Duplicate, and Delete.
- **Preserved Text Selection**: Reading and native text selection in View Mode remain 100% uncompromised.
