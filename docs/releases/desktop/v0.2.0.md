# iKeen Desktop v0.2.0 Release Notes

**Release Version:** `0.2.0`  
**Release Date:** `2026-11-22`  
**Target Platforms:** Windows x64 (`.exe`, `.msi`), macOS Apple Silicon (`.dmg`, `.app`), macOS Intel (`.dmg`, `.app`), Linux x64 (`.deb`, `.AppImage`)  
**Codename:** *Cross-Platform Scratchpad & Reminders Parity*  

---

## Executive Summary

iKeen Desktop 0.2.0 brings complete feature parity with mobile across the **Scratchpad workspace**, **Modular Note Blocks**, and **Note Reminders subsystem**, accompanied by timezone drift remediation, single-media block invariants, and Ably Realtime delta sync integration.

---

## What's New & Fixed in v0.2.0

### 1. Cross-Platform Scratchpad
* **AppSidebar Scratchpad Filter**: Dedicated sidebar navigation item (`activeFilter === 'scratchpad'`) displaying the persistent scratchpad note.
* **Scratchpad Picker Modal** ([`apps/desktop/src/components/modals/ScratchpadPickerModal.tsx`](../../../apps/desktop/src/components/modals/ScratchpadPickerModal.tsx)):
  * Seamless setup screen allowing users to create a new scratchpad note or select an existing tagged note.
* **Command Palette Action**: Fast keyboard shortcut action (`Ctrl+K` / `Cmd+K`) to jump directly to Scratchpad.
* **Archived Isolation**: Scratchpad notes remain excluded from the standard All Notes list while syncing seamlessly across devices via SQLite and Ably Realtime.

### 2. Timezone Drift Repair & Clean Reminders Parity
* **Local Date Formatting** ([`apps/desktop/src/components/modals/ReminderDialog.tsx`](../../../apps/desktop/src/components/modals/ReminderDialog.tsx)):
  * Fixed a bug where editing reminders shifted dates by ±1 day in timezones not coincident with UTC by using `formatLocalDateInput(d)` with local calendar components.
* **Reminder Dialog**:
  * Quick presets (Later Today 6 PM, Tomorrow 9 AM, Next Week), custom datetime picker, and repeat intervals.
  * Live reminder badge counter in AppSidebar.

### 3. Modular Note Blocks & Single Media Block Invariant
* **Modular Block Rendering**: Text, checklist, and media blocks integrated into `EditorPane`.
* **Zero Content Loss**: Safe conversion of markdown notes into structured blocks.
* **Interactive Checklist Editor**: Inline item editing, automatic Enter-to-focus for newly created items, and check toggling.
